# Netflix UI Clone

A front-end clone of the Netflix interface built using React and vanilla CSS. The project focuses on recreating the layout, styling, and component structure of a modern streaming platform UI.

## Overview

This project replicates the look and feel of Netflix, including content rows, banners, and responsive design. It is intended to practice component-based architecture and styling without relying on external CSS frameworks.

## Tech Stack

Frontend
- React
- JavaScript
- HTML
- CSS (vanilla)

## Features

- Responsive layout similar to Netflix
- Reusable React components
- Content rows and banner sections
- Hover effects and basic UI interactions

## How It Works

The application is structured into reusable components such as rows, cards, and banners. Styling is handled entirely with vanilla CSS to closely match the original design.

## Project Context

Built as a personal project to improve React fundamentals and CSS layout skills.
